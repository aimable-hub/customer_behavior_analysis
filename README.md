# Customer Shopping Behavior Analysis

## End-to-End Data Analytics Project | Python • PostgreSQL • SQL • Power BI

## 📌 Project Overview
This project demonstrates an end-to-end data analytics workflow simulating the responsibilities of a professional Data Analyst. The goal is to transform raw customer shopping transaction data into actionable business insights through data cleaning, analysis, SQL querying, database management, and interactive dashboard development.

The analysis is based on **3,900 customer transactions** and explores customer behavior, purchasing patterns, product performance, subscription trends, and revenue opportunities.

## 🎯 Project Objectives

- Clean and transform raw customer transaction data
- Perform exploratory data analysis (EDA)
- Engineer new analytical features
- Design and manage a PostgreSQL database
- Answer business questions using SQL
- Build an interactive Power BI dashboard
- Generate business insights and recommendations
